Stickman Tank Rush 🚀

🔧 Technologies Used

Unity, C#, DOTween, Array2D, ColorType, GridPathfinder, TriInspector, SerapkeremGameTools

💡 Description

Stickman Tank Rush is a hyper-casual puzzle game featuring the following key elements:

  • Tank and Stickman Matching 🟩🔴🟦: Stickmen match with tanks of the same color, offering a puzzle-like gameplay experience. The color-matching mechanic adds a strategic layer.
  • Grid-Based Movement System 🔲: Stickmen navigate the grid to reach tanks or holder areas. The grid layout is dynamically generated and managed.
  • Dynamic Level Creation 🎮✨: Each level uses ScriptableObject and Array2DGrid to define the grid layout, tank positions, and other elements.
  • Tank and Holder Areas 🟩🔲: Tanks are placed on grid cells, and filled holder areas result in a game over.
  • Colorful, Simple Graphics 🌈: Visually appealing and easy-to-understand gameplay mechanics with a minimalist design.
  • Seamless Animations: Implemented smooth transitions and movements using DOTween.
  • Mobile Optimization: Optimized for Android devices, ensuring smooth performance and a responsive experience.

Tiny Merge: A Matching Adventure 🎮

🔧 Technologies Used

Unity, C#, DOTween, TriInspector, Zenject

💡 Description

Tiny Merge is an exciting puzzle game designed to help me learn Zenject for dependency management. It challenges players to collect target objects, manage tiles, and use powerful joker abilities to advance through time-limited levels. Can you conquer all the levels before time runs out? ⏳✨

  • 🧩 Target Object Collection: Collect specific target objects to complete levels. 🎯
  • ⚡ Match-3 Mechanic: Align three of the same type of object to trigger a match and remove them from the board. 🔥
  • ⏰ Time Management: Each level has a time limit. If time runs out, the player loses. ⏳
  • 🔲 Tile System: Objects are placed on empty tiles. If all tiles are filled, the game is over. 🚫
  • 🎲 Special Joker Powers:
    • Destroy Triple Item – Removes three identical items from the board. 💣
    • Item Shaker – Applies random forces to items on the board, potentially creating new matches. 🌀
    • Recycle Item – Recycles the last collected item for reuse. ♻️
    • Freeze Time – Freezes time for a short period. ⏸️
