🏎️ City Car Racing 3D

🛠 Technologies Used

Unity, C#

📜 Description

This project is an exciting and dynamic 3D racing game developed using Unity. The game provides a thrilling racing experience, complete with realistic vehicle controls and immersive gameplay. Below are some of the key features:

  • 🚗 Vehicle Controls: The main car has been programmed with smooth and responsive controls to enhance the player's driving experience. This includes acceleration, braking, and steering mechanics that mimic real-world driving.
  • 🛣️ Race Track Design: Multiple race tracks have been designed with varying levels of difficulty. Each track is equipped with waypoints that guide AI-controlled vehicles along the designated route, creating challenging and competitive races.
  • 🤖 Artificial Intelligence: Advanced AI systems have been implemented for rival cars, allowing them to navigate the race track efficiently. The AI algorithms ensure that opponents react dynamically to the player's actions, creating a more engaging race.
  • 🛠️ Garage System: Before each race, players can visit the garage to select and customize their vehicle. The garage system offers a range of cars, each with unique attributes, allowing players to choose the car that best suits their racing style.
  • 🎥 Camera and UI Systems: The game includes a realistic camera system that follows the car, providing an immersive third-person perspective. The UI is designed to be intuitive, providing players with essential information such as speed, lap times, and position within the race.
  • 🔊 Audio and Visual Effects: High-quality sound effects and visual effects enhance the overall gameplay experience, making each race feel intense and exciting.

🎮 ColorChains 🔗

🔧 Technologies Used

Unity, C#, DOTween, TriInspector, SerapkeremGameTools, Physics & Hinge Joints

🧠 About the Game

A physics-based logic puzzle where players must strategically place keys into their matching sockets—all while managing chain constraints! But beware! Overstretching the chains will break them, and you only have a limited number of moves to succeed.

  • 🔗 Chain Constraints: Keys are physically connected to chains, restricting their movement.
  • ⚡ Break Mechanism: Chains will snap if stretched too far or subjected to excessive force.
  • 🔑 Key & Socket Matching: Match each color-coded key to its correct socket to progress.
  • ⏳ Limited Moves: Think carefully! You must solve the puzzle before running out of moves.
  • 🎮 Intuitive Controls: Drag & drop keys using touch or mouse input for a smooth experience.
  • 🎨 Engaging Visuals & Physics: Seamless animations and realistic physics make every move satisfying.

🎮 Tiny Merge: A Matching Adventure

🔧 Technologies Used

Unity, C#, DOTween, TriInspector, Zenject

🧩 About the Game

A fast-paced puzzle game where players must collect target objects, strategically manage tiles, and utilize powerful joker abilities—all within a race against time! Tiny Merge was also my first deep dive into Zenject, helping me master dependency management in Unity. 🚀

  • 🎯 Target Object Collection: Gather specific objects to complete levels.
  • 🔥 Match-3 Mechanic: Align three of the same type to clear them from the board.
  • ⏳ Time-Limited Challenges: Beat the level before time runs out!
  • 🚫 Tile-Based System: If the board fills up, it's game over.
  • 🎲 Powerful Joker Abilities: Gain an advantage with these special moves:
    • 💣 Destroy Triple Item: Instantly removes three identical items.
    • 🌀 Item Shaker: Applies random forces to shake up the board.
    • ♻️ Recycle Item: Reuse your last collected item.
    • ⏸️ Freeze Time: Temporarily stop the clock!
